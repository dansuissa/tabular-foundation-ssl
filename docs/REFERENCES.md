# References and upstream resources

These are the primary papers and official resources most directly connected to
the implemented benchmark families. Method names in this repository do not
automatically imply exact reproduction; consult [METHODS.md](METHODS.md) and
[tfm_ssl_fidelity.md](tfm_ssl_fidelity.md) for the actual implementation scope.

## Tabular foundation models

- Prior Labs Team. **TabPFN-3: Technical Report.** 2026.
  [Technical report](https://priorlabs.ai/technical-reports/tabpfn-3) ·
  [official implementation and releases](https://github.com/PriorLabs/TabPFN/releases)
- Hollmann, N. et al. **Accurate predictions on small data with a tabular
  foundation model.** *Nature* 637, 319–326 (2025).
  [Article](https://www.nature.com/articles/s41586-024-08328-6)
- Qu, J., Holzmüller, D., Varoquaux, G. & Le Morvan, M. **TabICL: A Tabular
  Foundation Model for In-Context Learning on Large Data.** ICML 2025.
  [Paper](https://arxiv.org/abs/2502.05564)
- Qu, J., Holzmüller, D., Varoquaux, G. & Le Morvan, M. **TabICLv2: A better,
  faster, scalable, and open tabular foundation model.** 2026.
  [Paper](https://arxiv.org/abs/2602.11139) ·
  [official documentation](https://tabicl.readthedocs.io/en/latest/)
